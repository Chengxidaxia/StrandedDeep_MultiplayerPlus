# StrandedDeep_MultiplayerPlus

Stranded Deep（深海搁浅）联机增强模组 —— 让游戏脱离 Photon Cloud 官方服务器，改为 **IP 直连联机**，并附带聊天框、单人存档复用等实用功能。

| 项目 | 内容 |
|------|------|
| 模组名 | MultiplayerPlus |
| 作者 | Chengxidaxia |
| 注入方式 | BepInEx（Harmony 补丁） |
| GUID | `com.chengxidaxia.multiplayerplus` |
| 依赖 | 游戏自带的 Photon Bolt + udpkit（无需额外运行时库） |

---

## 功能特性

- **IP 直连联机**：彻底脱离 Photon Cloud 服务器，不再依赖「连得上官方服务器才能玩多人」。组网方式交给玩家，模组只负责联机。
- **跳过建房页面**：房主「继续游戏」直接加载存档进入游戏，服务器后台自动监听，客户端随时加入。
- **客户端自选角色模型**：加入联机时可选择「男性 / 女性」模型，房主与服务端一致渲染。
- **聊天框**：MC 风格，半透明、左下角固定；支持滚动查看历史、emoji 表情、大小缩放。
- **单人存档复用**：多人联机直接读写单人存档（`data.json`），不再区分单/多人存档。
- **系统消息**：联机开启后自动广播监听端口与协议。

## 安装部署

1. 把 `MultiplayerPlus.dll` 放入游戏的 BepInEx 插件目录：

   ```
   {BeplnEx}\plugins\MultiplayerPlus\MultiplayerPlus.dll
   ```

2. 启动游戏，BepInEx 自动加载。首次运行后会在 `$BeplnEx目录$\config\` 生成配置文件。

---

## 配置项

| 配置键 | 默认值 | 说明 |
|--------|--------|------|
| `Network.ListenPort` | `27000` | 房主监听的 UDP 端口，客户端按此端口连接 |
| `Network.ConnectAddress` | `127.0.0.1:27000` | 加入弹窗里预填的 IP:端口（可每次手动改） |
| `Chat.Scale` | `1.0` | 聊天框缩放倍数（0.5 ~ 3.0） |

修改配置后需重启游戏生效。

## 联机流程

### 房主（创建联机）

1. 主菜单 → 多人游戏 → 继续游戏。
2. 直接加载存档进入游戏（无需建房页面），服务器在后台监听端口。
3. 把本机 IP（组网 IP）告诉好友。

### 客户端（加入联机）

1. 主菜单 → 加入联机。
2. 在弹出的输入框填写房主的 `IP:端口`。
3. 选择自己的角色模型（男性 / 女性）。
4. 点击「加入」，连接成功后自动进入游戏。

## 聊天框使用

| 按键 | 作用 |
|------|------|
| `T` | 打开 / 关闭聊天输入框 |
| `Enter` | 发送消息（发送后自动关闭） |
| `Esc` | 关闭聊天框 |

- 未打开时，新消息会短暂显示在左下角（约 5 秒）。
- 打开后可滚动查看全部历史消息。
- 仅在游戏内（非主菜单 / 暂停 / 背包界面）可用。

## 组网说明

模组只负责联机，不提供组网服务。请玩家自行选择组网方式：

- **同一局域网**：直接使用局域网 IP 即可。
- **跨公网**：推荐虚拟局域网工具，用虚拟 IP 互联。
- **端口转发 / frp**：房主有公网 IP 时，把 UDP 端口转发出去，客户端连公网 IP:端口。

> 协议为 **UDP**（Bolt 纯 UDP），房主需放行对应端口的 UDP 出入站。

## 技术说明

- 平台替换：把 Photon Cloud 平台（`PhotonPlatform`）替换为本地 UDP 平台（`DotNetPlatform`）。
- 直连：通过 Bolt 内部接口 `BoltCore.Connect(UdpEndPoint, IProtocolToken)` 建立 IP 直连，并绕过 udpkit 的反反射保护。
- 存档复用：patch `FilePath.GetSaveFileSuffix`，使联机读写单人存档。
- 聊天同步：复用游戏自带 `MultiplayerMessage` 消息广播机制，两端安装同版本模组即可互通。
- 模组制作：该模组完全由 `Deepseek-v4 Pro` 生成，`Chengxidaxia` 负责测试&调试。
